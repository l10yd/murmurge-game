# Murmurge

Браузерная physics-merge игра: сбрасывай зверьков, сливай одинаковых,
 собери Мурмур-Короля (уровень 11).

## Стек

- Vite + TypeScript + React
- Matter.js (вся физика)
- Canvas 2D рендер (процедурные спрайты, DPR-aware)
- Vitest (unit)

## Запуск

```bash
npm install
npm run dev      # дев-сервер
npm run build    # tsc + production build в dist/
npm run preview  # предпросмотр production-сборки
npm test         # vitest unit-тесты
```

## Управление

- Мышь / палец — горизонтальное движение зверька
- Клик / отпускание пальца / Space / Enter — сброс
- ←/→ или A/D — движение с клавиатуры
- Esc — пауза / отмена выбора способности

## Способности

| Способность | Цена | Эффект |
| --- | --- | --- |
| Отбрасывание | 1 | убрать одного зверька с поля |
| Левитация | 2 | гравитация вверх на 1.25 с |
| Встряска | 3 | импульсы всем телам 650 мс |
| Обмен | 3 | поменять двух зверьков местами (открывается после 6 потраченных очков) |

Коллекция — в меню паузы. Победа — создать Мурмур-Короля (L11).
